# ФСП Карьера — кликабельный макет

Макет обоих кабинетов платформы обратного найма (кандидат, работодатель) и дашборда валидации для жюри. Стиль — по брендбуку ФСП: цвета `#402FFF`, `#EC1D35`, `#1B1C21`, шрифт JetBrains Mono, логотипы и изображения из `assets/`.

## Запуск

```
python -m http.server 8765
```

Открыть http://localhost:8765. Можно открыть и `index.html` напрямую из проводника.

Переход между экранами — кнопкой «Экраны» в шапке или по ссылкам внутри макета. Состояние живёт в памяти страницы: если кандидат принял приглашение «Ладога Пэй», у работодателя в «Приглашениях» появятся его контакты.

## Демо-сценарий

Регистрация → профиль и PDF → тест-квест (3 сцены) → категория «Backend · Python · Middle» → работодатель пишет потребность → подборка с объяснением оценки → приглашение с контролем вилки → кандидат принимает → контакты у работодателя → отметка после собеседования.

Все компании, люди и цифры синтетические. Цифры на дашборде валидации — заглушки до прогона.
