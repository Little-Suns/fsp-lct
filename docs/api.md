# API ФСП Карьеры

Полная актуальная спецификация формируется самим приложением: `/openapi.json`, интерактивная документация - `/docs`.
JSON-запросы используют `Content-Type: application/json`; защищённые методы требуют заголовок `Authorization: Bearer <token>`.
Не передавайте токен в URL. Код входа проверяется через `/api/auth/verify`; при выходе токен отзывается.

## Поиск и обратный найм

| Метод | Запрос | Успешный ответ |
|---|---|---|
| GET `/api/employer/search` | Фильтры `spec`, `track`, `grade`, `skills`, `fsp`, `cf`, `hackathon`, `format`, `city`, `q`; `page >= 1`, `limit` от 1 до 100 | `SearchResult`: `items`, `total`, `page`, `limit`, `skills`, `facets`, `cap` |
| GET `/api/employer/needs/{need_id}/picks` | Своя потребность; `filters`, `variant` (`embed`, `rerank`, `full`), `limit` от 1 до 500 | `PicksResult`: потребность, карточки с объяснениями, категории, рынок, квота |
| GET `/api/employer/candidates/{public_id}` | Публичный идентификатор; необязательный `need_id` своей потребности | `CandidateCard`: анонимная карточка, компетенции, объяснение соответствия; без имени и контактов |
| POST `/api/employer/invites` | `candidate_id`, `role`, `salary_from`, `salary_to`, `format`, `description`; необязательные `need_id`, `task`, `lottery_id` | `InviteResult`: `invite`, `warnings`, `quota` |

В выдаче и счётчиках категорий участвуют только кандидаты с оценкой теста. Заявленный грейд не создаёт категорию.
Предварительная экспресс-оценка явно помечается; полная оценка подтверждает навыки. Карточка доступна только при действующих согласиях и открытом статусе.

В приглашении обе границы зарплаты обязательны, суммы - рубли в месяц на руки. Отсутствие вилки, неверный порядок границ,
слишком широкая вилка и нижняя граница ниже допустимой дают 422 с `detail.errors` и `detail.warnings`.
Приглашение может не иметь опубликованной вакансии. Контакты кандидата появляются в `invite.contact` только после принятия и при действующем доступе.

## Категория и тест

`POST /api/candidate/profile` принимает анкету `ProfileIn`. Изменение специализации или трека сбрасывает подтверждённую оценку,
компетенции и навыки; история сохраняется. При незавершённом тесте изменение категории возвращает 409.

`POST /api/quest/start`: `target_grade`, `mode` (`full` или `express`), `story`, необязательный `invitation_id`.
Повторный старт возобновляет текущую сессию. `/answer` принимает ответ на текущее задание; `/finish` завершает попытку.
Неудачный тест не присваивает нижнюю категорию и не меняет существующую. Новый тест на явно выбранный нижний уровень
позволяет добровольно изменить грейд; любая смена грейда полным тестом ограничена интервалом 90 дней.
До окончания интервала попытка сохраняется в истории без смены категории. Смена специализации не обнуляет интервал.

`GET /api/quest/result` возвращает текущую категорию и последнюю попытку этой специализации/трека, включая неприменённый результат.
`assigned=false` и `category.grade=null` означают, что категория ещё не присвоена; `target` описывает результат относительно выбранного уровня.
`GET /api/quest/history` возвращает список попыток с `spec`, `track`, `target_grade`, результатом и признаком `applied`; ответы и ключи не раскрываются.
У попыток, созданных до миграции `0011_quest_category`, `spec` и `track` неизвестны (`null`): старый профиль мог меняться,
поэтому миграция не подставляет нынешнюю категорию вместо исторической. После смены категории экспресс-тест тоже не обходит сохранённый интервал.

## Ошибки

Ошибки имеют поле `detail`: строку; объект `errors`/`warnings`; либо список ошибок валидации полей с `loc`, `msg`, `type`.
В OpenAPI описаны эти варианты и общие коды (конкретный метод использует применимые к нему):

| Код | Причина |
|---|---|
| 401 | Нет действующей сессии |
| 403 | Неверная роль, отозванное согласие или блокировка компании |
| 404 | Запись не существует или скрыта от пользователя |
| 409 | Конфликт состояния: дубликат приглашения, заполненная ёмкость, незавершённый тест при смене категории |
| 413 | Слишком большой файл или запрос |
| 422 | Неверные поля или нарушение правил предметной области |
| 429 | Квота или ограничение частоты |
| 503 | Недоступен необходимый компонент, например SMTP или песочница |

Контракты успешных ответов поиска, подборки, карточки, потребностей и отправки приглашения описаны моделями в OpenAPI;
дополнительные поля карточки сохраняются для подробного объяснения результата. Тест `test_api_schema.py` проверяет эти контракты.
