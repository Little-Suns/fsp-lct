# Сопроводительная документация ФСП Карьеры

Документация для жюри спецтрека ФСП (ТЗ, п. 3.4 и 5.2). Разделы — файлы `NN-*.md` в этой папке, по порядку номеров; `openapi.json` — спецификация API.

## О документе

ФСП Карьера — платформа обратного найма ИТ-специалистов. Кандидат один раз проходит адаптивный тест и получает категорию «специализация · трек · грейд». Работодатель описывает потребность, получает анонимную подборку с объяснением, почему кандидат в ней, и сам направляет приглашение с обязательной вилкой зарплаты. Контакты кандидата открываются только после того, как он принял приглашение.

Документ покрывает обязательный перечень ТЗ (п. 3.4) и вопросы, которые постановщики попросили раскрыть в письменных ответах.
